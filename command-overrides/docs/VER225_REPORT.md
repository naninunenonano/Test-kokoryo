## 実装

- `src/game.js` の `DEFAULT_RULE_SETTINGS` をオフライン・オンラインの標準値と共有する。`ruleSettingValue` は明示された任意値を優先し、初期資源0・雇用上限0も保持する。
- `INITIAL_DRAFT` はpackSize=8 / picks=5。従来どおり各巡1枚を選び、全員の選択後に残りの候補を次のプレイヤーへ渡す。3巡固定の分岐・自動デバッグ・Bot・実オンライン状態遷移を5巡へ更新する。
- HTMLの初期値、公開場補充の既定値、レジェンド選択の既定値、ドラフト進行と手札説明も更新する。
- 初期設定の既存イベント処理を共有スコープ内へ移し、設定変更イベントから設定・関数を正しく参照できるようにする。イベントの二重登録はしない。
- Bot初期資源の配分は従来の優先を維持し、合計0/1でも指定の総量に収めて開始できるようにする。
- 勝利到達後の既存の最終ターン順・ターン数は変更しない。30VPと任意44VPで既存の最終ターン処理を検証する。
- `cardCommands`、全能力定義、全設置効果処理、全パックJS、カードの種類・枚数を固定比較で保護する。

## 6人戦の既知の制約

現行S1〜S10は各4枚、合計40枚。各人8枚を配ると6人戦では48枚必要で8枚不足する。
ユーザーから「今後デッキを増やすため、そのときは問題のない形になる予定」と回答があったため、今回カードを追加・複製・他のカードで補充する変更は行わない。
2〜5人戦は8枚提示に対応する。現行デッキで6人戦を開始しようとした場合、必要48枚・現在40枚を表示して開始前に止め、空の候補で進行不能にならないようにする。
配布処理は実際のSカード総数を参照し、将来48枚以上になれば同じ処理で6人戦へ進める。テスト用の仮データだけを8枚加えた場合に6人へ8枚ずつ配れることを検証し、実際のデッキは40枚のまま維持する。
