# TEST Ver.0.3.239 — 全キャラクター統合・追加パック選択UI整理

基準: TEST238、Test-kokoryo main cdf1b77ff9909a6e949717f9a2ff2ac4baf3a088。

## 変更

- 本体・追加パック1・2の全領主24人（9ファミリー・12バージョン）を、旧パックON/OFFに関係なく選択可能にする。既存P-ID、画像ID、家族単位の同一人物選択制限を維持。
- 全雇用46種類を本体プールへ統合。元の追加パック定義は保持し、ID集合で重複登録／排出を防ぐ。
- 通常ガチャ候補はN7、R7、SR4、SSR3、UR12種類。既存の合成専用・CLR特殊獲得の条件は維持し、通常ガチャへ混入させない。N60/R20/SR11/SSR6/UR3の抽選率を変更しない。
- 一覧・特殊雇用・組織再編・レベルアップ等も統合プールを参照。モノマネ師、ドッペルゲンガー、CURユニーク／CUR13例外、CLR融合と能力選択を維持。
- ロビーの追加パック1・2の選択項目を、関連見出しとともに非表示にする。旧設定値を扱うDOM IDと保存形式は保持し、通常カード・レジェンドのパック設定や追加ルール設定は変更しない。
- キャラクター専用の統合対象IDを定義し、通常カード／レジェンド用isPackEnabledは変更しない。将来の新しいパックIDは従来通りON/OFFと追加登録に対応。
- pack1.js、pack2.js、rules_pack1.jsと拡張APIは変更・削除しない。
