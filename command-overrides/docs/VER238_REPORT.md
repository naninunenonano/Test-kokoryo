## 実装範囲

- 仮N20種を指定の旧カード15種＋新規5種へ置換。S15種×6枚＋N20種×6枚＝210枚。
- 旧Nの効果名・VP・設置コスト・画像パス・個体別onceを維持し、新番号で登録。採用したパック由来カードはパックを有効にしなくても使用可能。移行済みの旧番号を重複登録しない。既存プリセットの該当参照も新番号へ移す。
- N16: S/Nの通常ターン開始時効果を対象として選択。コピー元の通常発動回数を使わない。1回のコピー連鎖内で同一カード個体を再訪した時点で終了し、同名の別個体へのコピーは許可する。
- N17: 自身＋設置確定済みS/N1枚を原子的に捨てる。共通tobaを1回実行し、ネストした設置時効果の完了後にサイコロ1個、各資源1個。カード詳細は指示書の正式日本語文。
- N18: 自身＋設置確定済みS/N5枚。公開中・未獲得の下位／解放済み上位のみを選択。通常のコスト・個別条件・1ターン1枚制限・オーバークロック制限はこの特殊獲得時だけ無視し、既存の獲得後処理へ合流。通常獲得側の条件は維持。
- N19: 次の設置者ターン開始処理より前まで、他プレイヤーの領主／雇用の発動部分を抑制。データ定義や永続計算は変更しない。既存の同じ出目の命令書・ANY命令書と設置軽減も通常の支払い規則で利用可能。期限状態は保存状態にも含める。
- N20: 通常手札から任意選択。0枚を含み、捨てた枚数＋1枚を既存のdrawで引く。選択完了までは捨て札を確定しない。

## 移行時に確認した説明／実装の不一致

移行対象の本来の効果を守るため、次の処理を該当カードに限って整合させた。

- 確定ガチャ: 旧実装は設置だけで無料UR雇用していた。カードを捨て、通常雇用コストの2倍を支払う起動処理にする。
- 円満退職: 旧実装のURも選べる・支払い不要の解雇を修正。UR以外を選択し、通常雇用コストを支払って解雇した後、次の通常雇用1回の最低レアリティを保証する。
- 派遣会社: 旧実装の自身の雇用時だけの支払いを、他プレイヤーが雇用するたびに所有者へ支払う処理にする。
