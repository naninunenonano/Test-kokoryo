# TEST Ver.0.3.226 — スタンダード1 バランス調整

基準：TEST Ver.0.3.225 / f3e14fa63d6940ba6b02f3558a8575eb75028265。
対象：S5〜S8・S10、N1〜N14、LL1〜LL6、LU1・LU2・LU4〜LU6、計30種類。
本番 Ver.0.3.220 は変更しない。Ver225の標準初期設定と汎用コマンド登録・Pack APIを維持する。

## 実装

- コスト・VPのカードデータと拡大表示を更新。対象施設等の設置判定・支払い・UI・Botは `BALANCED_INSTALL_COSTS` を共有する。支払い全体を検証した後に消費し、命令書はインデックスの降順で処理する。通常ダイス・命令書・ANY・おねだりによる軽減を維持する。
- S5〜S7は資源3、S8は命令書2、S10は通常2。N4〜N6は資源5、N7は命令書3。通常開始時とcastの両経路に反映。
- N1は公開場入替→設置者から全員順に1種類全部獲得、を2セット。セット内で各人の獲得直後に補充しない。2セット目の開始で再入替・補充する。
- N3は山札から2枚を順番にtobaで仮設置。各設置時効果・N3の連鎖・N1の両セットを解決してから次のカードへ進む。山札不足は既存の捨て札再利用と空山札処理を使う。
- `installEffectStack` は関数を含まない継続状態としてオンラインスナップショットに保存。再接続・他プレイヤーの選択後に処理を再開する。`parkChoiceRevision` により旧セットの遅延・重複選択を拒否する。
- N2は自分5・他2。N8〜N10は該当ダイス1個×設置個体ごとに負債2。最終ターン・負債禁止・在庫制限は既存のacquireDebtを使う。出目変更・消費では反応しない。
- N8〜N10・N12・N13は `playerScaledGain()` を共有し、2人5／3人4／4人3／5〜6人2。N13は他プレイヤーの資源合計8以上を参照する。
- LL1〜LL3は固定VP6、S5〜S7のみ資源+3・VP+3。対応Sは資源3→6、VP1→4。N4〜N6は常に資源5・VP3。盤面の増減にVPが追従する。
- LL5・LU6のコストは1〜6中の異なる4種類（命令書ANY代用可）。LU1は2〜5の同じ出目6個。実支払いモーダルも同じ条件で検証する。
- LU2は個体ごとにonce 3/turnを使い、3回を別々に選択・castする。
- N11・N14はVPのみ1へ。LL4〜LL6・LU4〜LU6の指定された効果は維持する。既存の全追加パック固有カード、S1〜S4・S9・N15・LU3は変更しない。
- 同じIDの実体は共通カタログから生成されるため、スタンダード2・3・カスタムにも新データを適用する。
