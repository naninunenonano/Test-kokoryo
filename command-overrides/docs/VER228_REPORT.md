# TEST Ver.0.3.228 手札上限の訂正

基準：TEST Ver.0.3.227 / main `ddb06eb9559a40c3701d47b187a416d7e679ffe7`。

ユーザーの訂正は「初期手札10枚ではなく、手札上限10枚」。Ver227で追加した開始時の5枚補充を撤回する。

## 変更内容

- 初期手札：既存の8枚提示・5巡ドラフトで選んだ5枚を維持。開始時の追加ドローなし。
- 手札上限：標準値を6から10へ変更。設定画面の初期値、gameSettings.handLimit、設定未入力時のフォールバックを一致させる。
- 任意の上限設定をした場合はその値を優先する。倉庫の設置・仮設置1枚ごとの上限＋2は従来どおり加算する。通常カード・命令書・負債の数え方、超過時の破棄／返却と例外ルールも既存のまま。
- 領主共通効果の資源3個は維持。固有能力による追加分、好きな組み合わせでの選択、獲得禁止は既存処理を使う。
- オフライン・Bot・実オンライン開始コードから誤った補充／案内を除く。同期は既存のgameSettingsと手札スナップショットを使用する。
- 本番Ver.0.3.220、カード効果・コスト・VP、汎用コマンドの実装、追加パック、保存済みVer226仕様書は変更しない。

## 検証

ゲームの自動テスト214件合格。TESTビルド成功、隔離検証23件・時計33件・オフライン／BotのDOM画面遷移・JS13本の構文検査合格。結果はGitHub Actionsの当該コミットの実行記録でも確認可能。
追加・更新した確認：初期手札5枚の維持とカード保存、手札上限の表示とオフライン／Bot／オンライン適用、任意値と未入力フォールバック、10枚で終了可能／11枚で超過処理、倉庫補正、共通資源3個と個体能力の加算、模擬オンライン復元。
実Supabase複数端末とiPhone Safari実機は未確認。TEST配信のオンライン接続禁止は維持。
