# TEST Ver.0.3.229 《等価交換》

基準は公開済みTEST Ver.0.3.228（TEST main 497bf842335048f23133bbfefd0e809448d770fd）。作業ブランチ feature/equivalent-exchange-229-rebuild。上流本番・本番Supabaseへ接続せず作業。

## 変更

1. 有効な固有能力《等価交換》を領主・雇用・コピー・付与能力から検出し、開始時に資金5。重複不可、既存コピー可否を維持。
2. 共通resourceCostPlan/canPayResourceCost/payResourceCostで必要総数を検査・消費。指定資源優先、不足を資金→食料→兵力の順に自動支払い。Bot・UI・Pack APIも共用。失敗時は消費なし。通常の資源交換は従来どおり（等価交換1:1、それ以外3:1）。
3. 現行の資源参照VP（好景気・不況・黄金時代・世界恐慌・ナーロッパギルド・稲魂）に共通の仮想資源予算を割当。全カードの合計最大値をDPで算出。資源を消費せず、二重計上なし。現行の切上げ・切捨て・不足ペナルティ・負債加点は維持。計算量O(対象カード数×総資源数)、同じ状態はキャッシュ。全現行計算式ペアを総当たり照合。
4. 資源獲得の共通判定で3種の獲得不可を無視。《世界恐慌》取得ターンの資源巻戻しも対象。サイコロ獲得抑止など資源獲得不可以外の制限は維持。
