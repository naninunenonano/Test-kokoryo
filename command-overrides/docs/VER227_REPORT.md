# TEST Ver.0.3.227 開始手札・領主共通資源の修正

基準：TEST Ver.0.3.226 / main `1a4a9d2be102cbad357f9792b53dffbe9606cba1`。本番リポジトリへの書き込みなし。

## 修正

- 初期手札：8枚提示・5巡のドラフトは維持。全員の初期資源確定後、通常山札から各プレイヤーの手札が10枚になるまで追加取得する。既存の汎用drawを使用し、山札・捨て札再利用と供給不足時の停止は既存処理に従う。ドラフト選択カードを失わず、同じ開始処理を再度呼んでも10枚を超えて配らない。
- 実オンライン開始時も同じ処理を呼び、HOSTの開始盤面を既存スナップショットで共有する。オンラインの資源選択画面はドラフト5枚を表示し、ゲーム開始時に追加5枚となる案内を表示する。
- 領主共通資源：ターン開始時の基本値を1から3へ変更。既存の1個ずつの選択UIで合計3個を自由配分する。固有能力・コピーの追加分は既存どおり加算。神の贈り物がある領主は共通3＋固有3で合計6。対応雇用の固有資源3は別キューのまま。
- 獲得禁止、世界恐慌による開始時抑止、ターン終了時の手札上限、初期資源10個は既存処理を維持する。
- 各カードのコスト・VP・効果定義と既存パックJS、Ver226の保存済み汎用コマンド仕様書は変更しない。

## 検証

- ゲームの既存・追加自動テスト：213件合格（追加7件を含む）。
- TESTビルド・隔離テスト23件、時計33件、オフライン／BotのDOM画面遷移テスト合格。JS13本の構文検査合格。
- 追加項目：オフライン開始時の全員10枚とカード保存、供給不足、重複配布防止、共通3個の配分と4回目拒否・次ターンリセット、神の贈り物との加算、獲得禁止、Bot開始、模擬オンラインの手札と残り選択回数の復元。
- 既存テストの更新：開始後も手札5枚とする旧期待値、神の贈り物込み4個とする旧期待値を変更。ドラフト段階の5枚期待値は維持。scope225の許可対象には今回編集した開始処理・表示関数のみを追加。
- 実Supabase複数端末、iPhone Safari実機、既に進行中のVer226対戦からの途中移行は未確認。TEST配信は従来どおり接続禁止。
