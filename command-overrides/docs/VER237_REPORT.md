## 参照整合性

- 効果はspecialと既存の共通インストーラで継続し、S種別の専用分岐に移行カードが吸収されないよう調整。
- 画像は旧カードの画像パスを維持。仮Nは旧番号のイラストを表示しない。
- 追加パック1は登録時に旧N16〜25をN36〜45へ移す。パックファイルの効果は変更しない。夜逃げの参照もN42へ更新。
- 追加パック2の旧N26/27/29はS13/14/15として基礎Sへ登録し、Nとして二重登録しない。S13〜15はパック2の有効・無効にかかわらず利用可能。
- スタンダード2・3も共有の新S、仮Nを使用し、追加パック参照を新番号へ整合。旧N効果を仮Nへ引き継がない。
- 旧番号で保存したカスタムデッキとの混同を防ぐため、カスタム構成保存キーはv2へ分離。旧保存を削除しない。
- 《ナーロッパ祭》は旧S1〜S10の対象を新S1〜S8へ対応づける。除外した制限令/特別許可書は0VPなので失われる印刷VPはない。新たにSへ移ったカードを対象に加えない。算式・獲得条件は変更しない。
- 下位施設レジェンドはspecialによる参照を継続。その他レジェンド定義・公開/獲得処理は変更しない。
