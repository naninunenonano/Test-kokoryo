## オーバークロック

能力名と有効な領主/雇用/付与/コピー状態を共通判定し、最初の2自ターンは上下レジェンドを獲得不可。3自ターン目から可。既存コピー可否は維持（パーフェクト・イミテーションのコピー不可を解除していない）。

自ターン数はターン識別子で1回だけ加算し、再描画や同一ターンのbeginTurn再実行では加算しない。開始時特殊取得の前に加算。通常取得、特殊金融レジェンド、神々の黄昏の無料取得、registerInstallation、toba、場へのmove、デバッグ生成を同じ判定で防止。非レジェンドカードは影響なし。自ターン数と識別子は同期/デバッグ復元対象。

その他のオーバークロック効果（初回20資源、重複/コピー仕様）は変更しない。

## 神託

通常雇用は従来の共通雇用経路（通常は資金5＋サイコロ1、既存の無料雇用ルールも適用）を使用する。神託のレベルアップは通常雇用とは独立し、手札3枚を選んで捨てる。既存のレベルアップ対応表・SSR等の対象制限・雇用時とは異なるレベルアップ処理を維持する。

毎回、既存 `cardCommands.toba({owner})` を1回呼び、山札上から1枚をコストなしで仮設置し、共通の設置時効果を処理する。文章DSLは存在せず、このJS呼び出しが「toba 山札 1」に対応する。設置処理の重複実装や新たなカード名依存はない。能力テキストに《開拓ラッシュ》は使用しない。

1プレイヤー1自ターン合計3回。複数個体、領主、コピー間でも合計3回。新しい自ターンで回復し、同一ターン再開始や源個体変更では回復しない。通常雇用済みでも使用でき、神託を使っても通常雇用枠は消費しない。

手札不足、重複/不正選択、無効なレベルアップ先、山札/捨て札が両方空、相手視点、未解決の設置効果中では消費前に拒否する。山札が空でも既存捨て札があれば共通drawOneの再構築に従う。山札の最後の1枚でもカード総数を維持する。Botも同じuseOracleUpgrade経路を利用する。
